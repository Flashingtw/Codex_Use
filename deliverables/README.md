# 第 5 週 App Inventor 2 作業成品

成品：`W5_Practice.aia`（MIT App Inventor 2 專案原始檔，非 APK）。

## 匯入方式

1. 儲存庫發布到 GitHub 後，開啟 `deliverables/W5_Practice.aia`，點選 **Download raw file** 下載；亦可使用儲存庫的 **Code → Download ZIP**，解壓縮後取得此檔案。
2. 開啟 MIT App Inventor 2：https://ai2.appinventor.mit.edu/
3. 選擇「專案 → 從我的電腦匯入專案（.aia）」並選取下載的檔案。
4. 使用 AI Companion 連線測試，或從「建置」產生 Android APK。

## 包含內容

- 主選單。
- 練習 1：動態設定背景顏色、背景圖片及螢幕方向。
- 練習 2：調整左右按鈕的顏色、字體大小、高度、寬度、文字及粗體；同時勾選兩個按鈕時顯示提醒。
- 練習 3：依題目指定的男女標準判定 BMI，顯示小數第一位結果、對應圖片並以中文語音播報。

## 驗證與待確認事項

- 已驗證 ZIP 封裝、四個畫面、元件參照及積木邏輯模擬，共通過 116 項斷言。
- 尚未在 App Inventor 網站實際匯入、編譯或於手機執行。
- PDF 未附課程素材庫圖片，目前使用內建示意圖。繳交前請依課程要求替換六張結果圖；男女初始圖片與六張結果圖為分開的素材。
