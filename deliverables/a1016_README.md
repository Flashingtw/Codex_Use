# a1016：完成第二個練習

成品：[a1016.aia](a1016.aia)

以使用者上傳的 `a1016.aia` 為基礎，只更新 `Screen2` 的畫面設定與積木。`Screen1`、原有三張圖片及專案設定均保持原始位元組不變；沒有加入第三個 BMI 練習。

## 下載及匯入

1. 在 GitHub 開啟 `deliverables/a1016.aia`，按 **Download raw file** 下載。
2. 於 MIT App Inventor 2 選擇「專案 → 從我的電腦匯入專案（.aia）」。若已有同名專案，先將既有專案重新命名或備份，以保留原檔。
3. 使用第一頁原有的「切換」按鈕進入 `Screen2`。

## 第二個練習的操作

- 勾選「設定左邊的按鈕」或「設定右邊的按鈕」。
- 同時勾選時會提醒「一次只可設定一個按鈕」，保留原先選取並取消新勾選；切換前先取消原勾選。
- 使用清單調整背景顏色、文字顏色、字元尺寸、高度與寬度。
- 「文字」開啟輸入對話框；「粗體」切換粗體狀態。
- 未選按鈕就操作設定時會提醒先選擇按鈕。
