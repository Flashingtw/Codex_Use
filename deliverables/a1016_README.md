# a1016：完成第二個練習

修正版成品：[a1016_fixed.aia](a1016_fixed.aia)（`a1016.aia` 亦已同步修正）

以使用者上傳的 `a1016.aia` 為基礎，只更新 `Screen2` 的畫面設定與積木。`Screen1`、原有三張圖片及專案設定均保持原始位元組不變；沒有加入第三個 BMI 練習。

## 下載及匯入

1. 在 GitHub 開啟 `deliverables/a1016_fixed.aia`，按 **Download raw file** 下載。
2. 於 MIT App Inventor 2 選擇「專案 → 從我的電腦匯入專案（.aia）」。若已有同名專案，先將既有專案重新命名或備份，以保留原檔。
3. 使用第一頁原有的「切換」按鈕進入 `Screen2`。

## 第二個練習的操作

- 勾選「設定左邊的按鈕」或「設定右邊的按鈕」。
- 同時勾選時會提醒「一次只可設定一個按鈕」，保留原先選取並取消新勾選；切換前先取消原勾選。
- 使用清單調整背景顏色、文字顏色、字元尺寸、高度與寬度。
- 「文字」開啟輸入對話框；「粗體」切換粗體狀態。
- 未選按鈕就操作設定時會提醒先選擇按鈕。

## 驗證

已驗證 ZIP 封裝、元件連結，以及上述操作的積木邏輯模擬，共通過 243 項斷言。尚未在 AI2 實際匯入、編譯或於手機執行。

## 修正積木顯示紅色錯誤圖示

前一版的 `Screen2.bky` 將元件積木的 `mutation` 標籤輸出為帶命名空間前綴的 `html:mutation`，使 Blockly XML 讀取器無法辨識元件資訊。現在改為與使用者原檔相同的無前綴標籤格式。

已使用 App Inventor 官方原始碼儲存庫內的 Blockly XML 讀取器，配合最小元件定義重現並驗證：舊格式只載入 11 個缺少元件資訊的事件積木；修正後完整載入 140 個積木、11 個事件，沒有讀取器警告。這是解析層級驗證，不代表已在完整 AI2 介面或手機上執行。

請下載新版 `a1016_fixed.aia` 並匯入為新專案；已匯入的舊專案不會隨 GitHub 檔案更新而自動修復。
